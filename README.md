# Equiply – Equipment Rental Platform

**Rent Smart. Work Better.**

## Project Overview

Equiply is a modern equipment rental platform that makes it easy for customers to find and rent equipment online. Equipment owners can list and manage their equipment, while administrators can manage users, equipment listings, and rental activities through a dedicated dashboard.

## Live Website

[Visit Equiply](https://equiply-nu.vercel.app/)

## Key Features

- **User Authentication:** Secure sign-up and sign-in with email and Google authentication.
- **Role-Based Dashboard:** Separate dashboards for Customers, Owners, and Admins.
- **Equipment Browsing:** Explore available equipment with search, category filters, sorting, and price filters.
- **Equipment Management:** Owners can add, update, and manage their equipment listings.
- **Rental Booking:** Customers can book equipment and manage their rental activities.
- **Online Payment:** Integrated Stripe Checkout for secure rental payments.
- **Favorites:** Customers can save their favorite equipment for later.
- **Admin Dashboard:** Administrators can manage users, equipment, rentals, and platform analytics.
- **Owner Analytics:** Equipment owners can monitor their equipment and rental activities.
- **Responsive Design:** User-friendly interface for desktop, tablet, and mobile devices.

## Getting Started

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Configure Environment Variables

Create a `.env.local` file and add the required environment variables for authentication, API configuration, Google login, and other services.

Configure the backend environment variables separately.

### 4. Run the Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
